# Jester Quotes — Public Image Assets

## Canonical directories

| Location | Responsibility | Rules |
|---|---|---|
| `public/images/` | Manually created brand, editorial, collection and promo artwork | Flat directory; descriptive filenames; reviewed before inclusion |
| `public/social/quotes/` | 100 programmatically generated quote preview PNGs | Generated by `npm run social:generate`; do not move or hand-edit |
| `public/og-jester-quotes.png` | Generated default Open Graph preview | Maintain its existing URL and generator |
| `public/favicon.svg`, `public/apple-touch-icon.png`, `public/site.webmanifest` | Active browser and PWA identity assets | Replace only as an explicit, validated brand update; preserve public paths |
| `src/assets/` | Existing imported SVG illustrations and decorative patterns | Leave these in Astro's source asset pipeline |

Do not create a root `assets/` directory, a nested `public/images/branding/` or `public/videos/` without an actual need. Keep `public/social/quotes/` at its current path.

## Integration contract

- Upload raw image files to `public/images/` without moving or renaming existing files.
- For collection listings use a clean image with an accessible HTML title. Use editorial image text for featured banners where appropriate; don't repeat the image title in an overlaid visual element.
- Add image references to collection metadata **only after those exact files exist**. Until then retain the currently working CSS collection cards.
- Supply meaningful alt text, stable intrinsic dimensions, responsive `sizes` and appropriate loading priorities. Avoid loading all large covers at full size on the homepage.
- Optimize photos/illustrations before shipping; prefer modern responsive derivatives when implemented. Keep approved originals or authoritative PNGs at their documented URL.
- Social/OG images are a separate generated system. Do not replace generated quote previews with manually designed collection covers.
- After each asset integration, check Astro build/tests, responsive cropping, links, and Vercel Production. Do not update the current default OG preview merely because an unrelated wide hero was uploaded.
